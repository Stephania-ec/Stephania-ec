   Proyecto destacado: 'Sistema de Arriendo de Inmuebles'

Es una aplicación web que se desarrolló con Django y PostgreSQL, que permite gestionar inmuebles y solicitudes de arriendo.

  Principales funcionalidades:
   
📂 Registro e inicio de sesión de usuarios .
📂 Perfil Arrendador y Arrendatario.
📂 Gestión de inmuebles mediante CRUD.
📂 Búsqueda por comuna y región.
📂 Solicitudes de arriendo.
📂 Aceptación y rechazo de las solicitudes.
📂 Uso de ORM de Django y relación entre modelos.

Ver proyecto en GitHub 💻 (https://github.com/Stephania-ec/sistema-arriendo-inmuebles)
